Langkah Publikasi

Timeline Hosting & Domain

Delapan tahap dari ide sampai website bisa dibuka lewat internet.

  1. 1

    Perencanaan

    Tentukan tujuan website, isi halaman, pembagian tugas, dan gaya desain. Ibarat merancang topologi jaringan sebelum memasang kabel.

  2. 2

    Pembuatan Website

    Tulis kode HTML untuk struktur, CSS untuk tampilan, dan JavaScript untuk interaksi menggunakan VS Code.

  3. 3

    Pengujian Lokal

    Buka website di komputer sendiri (misalnya dengan Live Server). Cek tombol, menu HP, modal, dan tampilan di berbagai ukuran layar.

  4. 4

    Memilih Hosting

    Hosting adalah "server" tempat file website disimpan agar bisa diakses 24 jam. Bandingkan harga, kapasitas, dukungan, dan apakah ada HTTPS gratis.

  5. 5

    Upload File

    Kirim index.html, style.css, dan script.js ke hosting lewat File Manager, FTP, atau fitur upload penyedia. Pastikan struktur folder tetap sama.

  6. 6

    Menghubungkan Domain melalui DNS

    Domain adalah alamat website. Lewat pengaturan DNS, kita mengarahkan domain ke server hosting dengan record seperti A atau CNAME, atau nameserver dari hosting. Perubahan DNS bisa butuh waktu untuk menyebar (propagasi).

  7. 7

    Mengaktifkan HTTPS

    Pasang sertifikat SSL agar koneksi terenkripsi dan muncul ikon gembok di browser. Banyak hosting menyediakan SSL gratis.

  8. 8

    Pengujian Online

    Buka alamat domain dari laptop dan HP, juga dari jaringan lain. Cek semua halaman, gambar, tombol, kecepatan, dan HTTPS sebelum dibagikan.
